# The Zero Card Special Rule

## The Most Powerful Card? 🃏

The **Zero Card (0/0)** has a unique ability that makes it incredibly strategic!

![Zero Card](https://placehold.co/600x400/a855f7/ffffff?text=Zero+Card+Power)

## Special Ability

The Zero Card can **defeat ANY Sentinel**—regardless of its defense value!

### How It Works

**Condition 1: Solo Attack**
- Attack with **only the Zero card**
- ATK = 0, but special rule applies
- Defeats any Sentinel (even DEF 9+)

**Condition 2: Zero-Sum Combo**
- Attack with **multiple cards that total 0 ATK**
- Example: [0, 0] → Total ATK = 0
- Special rule triggers!

## Exception: Zero vs Zero

The **only** Sentinel that resists Zero's power is... another Zero Sentinel!

- If Sentinel contains a Zero card → Zero attack **fails**
- This creates interesting defensive plays

## Strategic Uses

### When to Use Zero Offensively
- Enemy has high-DEF Sentinel (8, 9 cards)
- You need a guaranteed capture
- Surprise attack when opponent feels safe

### When to Declare Zero as Sentinel
- Defensive play against potential Zero attacks
- Force opponents to use regular attacks
- Risky: Only 0 DEF against normal challenges!

## Example Scenarios

**Scenario 1:**
- Sentinel: [9, 8] → DEF = 1 + 2 = 3
- Attack: [0] → Special Zero rule
- **Result:** ✅ Zero wins despite 0 ATK < 3 DEF!

**Scenario 2:**
- Sentinel: [0, 5] → Contains Zero
- Attack: [0] → Zero vs Zero
- **Result:** ❌ Zero power nullified!
